# My First VS Code Plugin

**Автор:** Гарибян Роман M3118
**Название плагина:** My First Plugin  
**Среда разработки:** Visual Studio Code

## Описание возможностей:
1. **Hello World** - показывает приветственное сообщение
2. **Show File Info** - отображает подробную информацию о файле:
   - Имя файла
   - Количество строк
   - Язык программирования
   - Размер в байтах
## Установка и запуск:
1. Клонировать репозиторий
2. `npm install`
3. `npm run compile`
4. Нажать F5 для запуска в режиме отладки

## Архитектура VS Code:
- **Extension Host** - отдельный процесс для выполнения плагинов
- **API Layer** - предоставляет безопасный доступ к функционалу IDE
- **Activation Events** - события, запускающие плагин
- **Contribution Points** - регистрация команд в package.json
